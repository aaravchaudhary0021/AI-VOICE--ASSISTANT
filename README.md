# 🎙️ AI Voice Assistant

A Python-based voice assistant that performs tasks using voice commands.

## 🚀 Features
- 🎵 Play songs on YouTube
- 🔍 Google search
- 🌐 Open websites (YouTube, Google, Instagram, GitHub)
- ⏰ Tell current time
- 😂 Tell jokes
- 📩 Send WhatsApp messages
- ✍️ Auto typing & handwriting

## 🛠️ Tech Stack
- Python
- SpeechRecognition
- pyttsx3
- pywhatkit
